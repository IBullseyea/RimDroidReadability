# Gameplay screenshots

All 11 distinct current screenshots supplied by the player on Samsung S25 FE / RimDroid 0.3.0v2 are included. Image pixels are unchanged; capture timestamps, image identifiers and other unnecessary EXIF metadata were removed from the publication copies. The original folder contained a second identical copy of each image.

The gallery covers colonist indicators, pause/shortcut tooltips, all items, medicine, wood, weapons, food, resources, apparel and returning to Items off. The images show the English UI; they do not establish complete font or performance acceptance on every language/device.

Screenshots contain third-party game artwork and UI, whose rights remain with the respective owners. The mod's MIT license does not relicense that artwork. Images are presentation assets and are excluded from the installable mod ZIP.
